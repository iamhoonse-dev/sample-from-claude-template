🥛 클렌징 밀크에스트라 아토베리어365 클렌징 밀크저녁 1차 클렌징
🫧 순한 클렌저에스트라 아토베리어365 젠틀 포밍클렌저아침용
🫧 폼 클렌저뉴트로지나 아크네 포밍 클렌저 / 이니스프리 화산송이 BHA 클렌징폼저녁 2차 / 운동 후
🪒 면도질레트 스킨텍 쉐이빙 폼아침 면도 시 사용
💧 토너라로슈포제 판테놀 시카에센스 토너진정 + pH 정돈
✨ 에센스에스트라 아토베리어365 하이드로 에센스수분 + 장벽 강화
🧴 크림에스트라 아토베리어365 크림보습 마무리
💊 크레오신한독제약 크레오신 (처방)여드름 부위에만 톡톡

💡 주요 원칙

🌅
아침 (출근일)
순한 클렌저로 세안 → 면도 → 스킨케어 → 크레오신 → 선크림
🌙
저녁 (출근일)
더블 클렌징(밀크+폼) → 스킨케어 → 크레오신
🏠
재택 근무
출근일과 동일하되 선크림 생략, 저녁에 클렌징 밀크도 생략 (창가 작업·외출 시에는 선크림 사용 → 저녁 더블 클렌징)
🏋️
쉬는 날 운동 전
간소화 루틴 (세안 + 면도 + 토너 정도)
🚿
쉬는 날 운동 후
운동 후 샤워하면서 풀 루틴
💧
제형 순서
묽은 것 → 진한 것 순서로 도포
💊
크레오신
크림 다음 마지막 단계에 여드름 부위에만 사용
🥛
더블 클렌징 기준
선크림을 바른 날만 클렌징 밀크 사용, 안 바른 날은 폼 클렌저만으로 충분
🔮
향후 고려 (치료 종료 후)
앰플: 치료 완료 후 피부가 안정되면 특정 고민(미백, 안티에이징, 진정 등)에 맞춰 토너와 에센스 사이에 추가 고려
재생크림: 피부과 시술 받은 날 저녁에 일반 크림 대신 사용 고려
